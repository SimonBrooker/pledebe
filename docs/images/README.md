# Screenshots

Referenced from the top-level README. Capture from a running instance at a
desktop width (~1200px) so the stat grids lay out in multiple columns.

| File | What to capture |
|---|---|
| `status.png` | The top of the page: verdict banner, the findings list, and the first measurement group. This is the hero image. |
| `findings.png` | The integrity and full-text index sections, ideally with the deep-check figures populated. |

Notes:

- Use the **dark** theme; the page follows the browser, and it is what most
  people will see.
- Check for anything you would rather not publish before committing: the Paths
  group shows filesystem paths, and the crash section can show a Plex version
  history.
- PNG, and crop to the content rather than the whole browser window.
