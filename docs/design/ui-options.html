Design directions · 28 July 2026

pledebe — three ways to show a Plex admin what's wrong

Same data, same palette, three different information architectures. The difference between them is structural, not cosmetic: each answers a different question an admin actually arrives with.

The constraint that shapes all three

Healthy

Measured, and within expectations.

Attention

Measured, and outside them. Action available.

Fault

Measured, and broken now.

Unknown

Not measured. Not a fault. Must never read as either reassurance or alarm — it gets a hollow mark and a dashed border so it is legible as absence.

Direction A · selected

Verdict

One unambiguous state at the top, the way a smoke alarm reads. Everything below it is supporting evidence in descending severity. An admin can answer “do I need to care?” without reading a single number, then keep going if the answer is yes.

Best when the page is glanced at, or embedded in a dashboard

Direction B

Panel

An instrument panel. Every tracked value carries its own history, and a single timeline underneath ties events together — Plex upgrades, deep checks, crashes, the day a number changed shape. Built for the question “when did this start?”, which is the one that actually leads to a diagnosis.

Best when something is wrong and you're looking for the cause

Direction C

Triage

Organised around the decision, not the measurement. One thing to do, stated in the user's terms, with the evidence folded underneath rather than in front. Everything healthy collapses to a single quiet line — because a list of things that are fine is noise when one thing isn't.

Best when the admin wants to be told what to do, not what was measured

What's wrong
All four of Plex's full-text search indexes fail their integrity check, and 334,374 records are missing from them.
What you'd notice
Adding items to a collection or editing metadata fails, sometimes with a “database disk image is malformed” error. Searching still works normally, which is why this usually goes unnoticed.
What to run

These aren't mutually exclusive. Verdict is the natural front page, Panel is what a “History” tab should become, and Triage is what a finding should expand into when you click it. If one has to ship first, Verdict is the cheapest and the hardest to get wrong.
